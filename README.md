# Cooking Process

A private local listening kitchen for comparing, rating, and developing music snippets.

## What it does

- Drag in MP3, WAV, M4A, AIFF, or FLAC files
- View waveforms and loop ideas
- Compare two sounds with an A/B tasting table
- Hide filenames with Blind Taste mode
- Rate, stage, reorder, and annotate snippets
- Automatically shortlist 4–5 star ideas

Audio never uploads to a server. Files remain on the listener's device, while notes and ratings are stored locally in that browser.

## Use it

Open the live GitHub Pages site and drag your audio files into the kitchen.
